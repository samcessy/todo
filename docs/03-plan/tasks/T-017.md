## Notes

- `TodoItem` gets the icon buttons `Edit "<title>"` (`todo-<id>-edit`) and `Delete "<title>"` (`todo-<id>-delete`).
- `TodoEditDialog`: kit reka-ui `Dialog` titled `Edit todo`, inputs `todo-edit-title`, `-description`, `-due_date`, initial focus on the title; always sends all three fields (contracts §2); `Save` and `Cancel`; stays open on errors and focuses the first invalid field (F-f); focus returns to the edit trigger after save, cancel or Escape (F-d, F-e).
- `TodoDeleteDialog`: kit reka-ui `AlertDialog` titled `Delete todo?`, description `"<title>" will be permanently deleted.`, initial focus on `Cancel`; cancel sends nothing (F-g); after a confirmed delete focus moves per F-h.
- Browser tests: `US-04.AC1` (2), `US-06.AC1`, `US-06.AC2`, `US-06.AC4` (2), `CC.AC2` edit-dialog errors.
