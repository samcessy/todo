## Notes

- `bootstrap/app.php`: the 419 handler (`Inertia::flash('toast', ['type' => 'warning', 'message' => 'The page expired, please try again.'])` and `back()`); a `report()` callback for `QueryException` that logs only `getSql()` and the error code and stops default reporting.
- `HandleInertiaRequests`: `auth.user` = `$request->user()?->only([...])` with the keys from contracts §4 as corrected by T-005.
- **Boost browser logs (security review T-001 A-1, T-22).** Set `'browser_logs_watcher' => false` in `config/boost.php` (line 119 after T-001). When on, Boost registers `POST /_boost/browser-logs` locally without auth or CSRF and the `browser-logs` MCP tool feeds what it receives to agents, so any website the developer visits could plant text in an agent's context.
- **`boost:execute-tool` (security review T-001 A-3).** That hidden command checks only `boost.mcp.tools.exclude`, not the two switches, so the exclude list is what stops Tinker over Bash. `BoostConfigTest` asserts `ToolRegistry::isToolAllowed()` is false for `Tinker` and `RecordRule`, both switches are false, and `browser_logs_watcher` is false (names prefixed `T-19`, `T-22`).
- Tests: `CsrfConfigTest` `T-05` (2), `CsrfHandlerTest` `T-05`, `QueryExceptionLoggingTest` `T-12`, `SharedPropsTest` `T-04` (exact key set), `BoostConfigTest` `T-19` (keys from T-001/T-005; runs only where Boost is installed), `HealthTest` `NFR-10`.
